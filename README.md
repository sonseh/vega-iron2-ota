# 베가 아이언2 (IM-A910S/K/L, ef63) LineageOS 24.0 OTA

이 저장소는 베가 아이언2용 비공식 LineageOS 24.0(Android 17) 빌드의 OTA 업데이트 정보를 제공합니다.

- `ef63.json`: 폰의 **설정 > 시스템 > 업데이트**(LineageOS Updater)가 읽는 업데이트 목록입니다.
- 빌드 파일(zip)은 이 저장소의 **Releases**에 올라갑니다.

## 처음 설치

처음에는 Releases의 ROM zip을 **리커버리에서 직접 설치**합니다(리커버리는 `recovery-19.1-lzma` 릴리스에 있습니다). 그다음부터는 설정의 업데이트 메뉴에서 새 빌드를 받아 설치할 수 있습니다.

## 업데이트 방법

1. 설정 > 시스템 > 업데이트에서 새로고침합니다.
2. 새 빌드를 다운로드한 뒤 설치를 누릅니다.
3. 폰이 리커버리로 재부팅되어 설치하고, 다시 부팅됩니다(데이터 유지).

## 주의

- **업데이트 설정에 "복구 모드 업데이트"(Update recovery)가 보이면 절대 켜지 마세요.** 켜면 부트로더가 띄울 수 없는 큰 리커버리가 기록되어 리커버리가 망가집니다.
- 비공식 빌드입니다. 업데이트 전에 중요한 데이터는 백업하세요.
- 이 OTA는 system과 boot만 갱신합니다. 리커버리, 부트로더, 모뎀은 바뀌지 않습니다.
- 빌드는 AOSP test-keys로 서명되어 있습니다.
- GApps 등 직접 설치한 추가 zip은 업데이트 후 사라질 수 있습니다.
